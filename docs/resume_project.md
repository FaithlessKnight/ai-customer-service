# 简历项目描述

## 可直接使用的版本

**项目名称：基于 LangGraph 与混合 RAG 的电商智能客服及私域运营系统**

**技术栈：** Python、FastAPI、LangGraph、LangChain、Milvus、PostgreSQL、Redis、Ollama、Docker、Nginx。

**项目简介：** 面向电商咨询与客户运营场景，构建集商品问答、订单物流查询、售后人工接管、CRM 主动触达及朋友圈互动于一体的智能体服务，支持多品牌角色配置、知识库维护和多轮会话。

**核心工作与技术亮点：**

- 基于 LangGraph 设计情绪与意图分析、业务路由、工具调用、知识检索和回复生成流程，通过单次结构化分析提取情绪、意图与客户画像，并使用 Send 并行处理订单与知识复合诉求。
- 构建 Milvus 向量检索与 PostgreSQL 文档驱动的 BM25 双路召回，结合 jieba 中文分词、加权 RRF 融合与去重，支持多知识库检索、异常降级及可配置超时。
- 实现多轮会话持久化与连接恢复，支持 Redis、PostgreSQL、Memory 逐级降级；结合多品牌 Persona 与 CRM 生命周期字段，串联被动咨询、主动触达及静默转人工流程。
- 建设文档加载、文本清洗、分块与入库管道，提供知识库管理页面及统一 CLI，支持暂存处理、按来源替换、删除和重建，便于维护产品知识及销售话术。
- 使用 FastAPI 提供业务接口，集成 API Key、Redis 分布式限流及健康检查，配套 Docker 多阶段构建、Nginx 三实例部署配置，以及安全、接口契约、检索质量与性能评测脚本。

## 篇幅有限时的精简版

**电商智能客服与私域运营系统｜Python / FastAPI / LangGraph / Milvus / PostgreSQL / Redis**

- 基于 LangGraph 构建情绪与意图分析、业务路由、工具调用和回复生成工作流，支持多意图并行处理、多品牌角色配置与售后静默转人工。
- 实现 Milvus + 中文 BM25 混合召回及加权 RRF 融合，配套文档清洗、分块、入库与按来源更新链路，支持产品知识和销售话术维护。
- 对接 CRM 客户生命周期，构建主动触达子图与多轮会话持久化，提供 FastAPI 接口、Redis 分布式限流和 Docker / Nginx 多实例部署方案。

## 面试口述参考

这个项目面向电商客服和私域运营。我用 LangGraph 将消息分析、业务路由、检索、订单工具和回复生成拆成明确节点，让不同问题走不同流程。对同时询问订单和商品的消息，工具与检索会并行执行；对售后接管场景，直接返回转人工信号，由 CRM 统一发话。知识检索采用 Milvus 与中文 BM25 双路召回，通过 RRF 融合结果。除此之外，项目还提供多品牌角色配置、CRM 主动触达、知识库更新和会话持久化，并配套服务鉴权、限流及容器部署配置。

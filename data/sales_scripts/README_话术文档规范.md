# 话术知识库编写规范

本目录存放**正式标准**的销售话术，当前共 **3 份 Markdown**，与业务在用的桌面 TXT 一致；历史测试用的多文件拆分稿已移除。入库检索的**最小元数据**为 **`scene` + `journey_stage`**（与 CRM、`/cs`、`/cs/outreach` 一致）。

---

## 一、标准文档列表

| 文件 | `scene` | `journey_stage` | 说明 |
|------|---------|-----------------|------|
| `场景一销售话术.md` | `trial_not_used` | `first_outreach` | 领取体验装后未使用 |
| `场景二销售话术.md` | `trial_used` | `feedback_collecting` | 领取体验装后已使用 |
| `场景三销售话术.md` | `first_order_no_rebuy` | `post_order_care` | 首单后约 2 个月未复购 |

**维护方式**：编辑桌面 `场景一/二/三销售话术.txt` 后，在仓库根目录执行 `python scripts/desktop_scripts_add_metadata.py`，会覆盖写入上述三份 `.md`（需本机桌面路径存在对应 TXT）。

**入库**：`python scripts/ingest_sales_scripts.py --source data/sales_scripts --dry-run`

---

## 二、单文档结构（当前标准）

每份文档**至少**包含：

```markdown
# 文档标题

## 一、适用场景标签
（见下：必填表格）

## 二、话术正文
（可直接粘贴运营稿；可按业务再拆多级 ## 以便分块入库）
```

### 模块说明

#### 1. 适用场景标签（入库元数据）

话术写入向量库时，**每个文档顶部的「适用场景标签」表格中，以下两列必填**，并与 CRM 调用 `/cs`、`/cs/outreach` 时传入的字段一致，便于按 **场景 × 阶段** 过滤检索：

| 字段 | 类型 | 说明 |
|------|------|------|
| `scene` | string | 客户所处生命周期场景。当前有效场景：`trial_not_used`（领体验装未用）/ `trial_used`（已用体验装）/ `first_order_no_rebuy`（首单后未复购）。**完整枚举**以服务端 `_VALID_SCENES` 为准。**普通客服对话请求可不传 scene**，仅话术库与主动触达需要打标。 |
| `journey_stage` | string | 当前子阶段，由状态机维护。示例：`first_outreach`、`feedback_collecting`、`post_order_care`、`objection_price`、`refusal_closing` 等；与 `docs/journey_stage_spec.md` 及 CRM 配置保持一致即可。 |

**最小可用表格示例**（复制后改值即可入库）：

```markdown
| 字段 | 值 |
|------|-----|
| scene | trial_used |
| journey_stage | feedback_collecting |
```

**可选扩展列**（同一表格中可追加多行，入库脚本会一并写入 chunk 元数据，用于更细检索或运营备注，**非必填**）：

| 字段 | 说明 |
|------|------|
| `trigger_condition` | 触达条件文字说明 |
| `intent_level_range` | 建议意向区间，如 `20-60`（会解析为 `intent_level_min` / `intent_level_max`） |
| `required_slots` | 槽位条件说明 |
| `allowed_actions` / `forbidden_actions` / `next_stage` | 行为边界与下一阶段提示 |

> **约定**：`scripts/ingest_sales_scripts.py` 从全文**第一个**以「`| 字段 |`」表头开始的 Markdown 表解析上述键；缺 `scene` 或 `journey_stage` 时会打日志告警，请补全后再入库。

#### 2. 话术正文

与运营定稿一致即可；若以 `:` 分行表示多条变体、用 `---` 分段，无需再改格式。若单文件过长、希望检索块更小，可在正文中增加 `## 三、…` 等小节标题（入库脚本按 `##` 切 chunk）。

## 三、话术编写原则

### AI 人设
- **名字：** 小新
- **形象：** 25 岁左右年轻女销售，活泼、亲和、有自己的想法，不油腻
- **语气特点：**
  - 多用语气词（呀/呢/啦/嘛/嗷/诶/呢/哦哦）但不堆砌
  - 适度卖萌但不过度（避免"么么哒"、"哒")
  - 有自己的反应（"诶"、"哦哦"、"呜"），不是纯服务感
  - 敢开玩笑、敢吐槽，像朋友
- **避免：** "亲"、"宝宝"、"宝"、"小仙女"、"姐妹"、"亲爱的"、"买它"、"冲鸭"、"yyds" 这类过度营销或网络梗词

### 语言风格
- **像朋友，不像客服** — 用口语，不用书面语
- **短 > 长** — 单条消息不超过 30 字，超过就拆分
- **有温度，不空洞** — 避免"非常感谢""亲爱的"等套话
- **克制，不油腻** — 不要过度热情，保持销售顾问的专业感

### 销售节奏
- **先聊感受，再谈购买** — 未确认体验前不促单
- **一次只做一件事** — 不在一条消息里既追问又推购买
- **留钩子，不逼单** — 客户没回应时，给台阶而不是追问

### 产品提及规范
- 产品全名："新肌秀舒净雅香沐浴乳"（话术中可简称"沐浴乳"/"这款"）
- 规格：500ml/瓶、100ml/瓶
- 核心卖点："皂基+温和表活复配清洁"、"甘油保湿"、"蓖麻油滋润"
- **禁止提及化合物全名**（如"月桂基羟基璜基甜菜碱"）
- **禁止绝对化承诺**（如"绝对保湿"、"一定好用"）
- 购买链接：`#小程序://新肌秀New/IZwsn2JSuw5iNUJ`

### 转人工规则
以下情形话术中**必须**标注"转人工"：
- 客户明确提退款、退货、换货
- 客户表达强烈不满或投诉
- 客户疑似产品不良反应（过敏、刺激）
- 超出 AI 处理能力的问题（物流纠纷等）
